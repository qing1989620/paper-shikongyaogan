# 20 个创新点与对应实验设计（全部锚定真实论文，全部可运行）

日期：2026-11-18
前提：冻结 STFDiff model6 backbone，只用首步输出 x1 + 样本自带的 reference pairs，**不训练、零新增网络参数**。
因此 20 个创新点全部设计为**推理期算子**，可在 CPU 上逐个真跑（不是纸上方案）。

协议纪律：
- λ ∈ {0.2, 0.3, 0.5, 0.75} 只在 **validation** 上选；选定后原样用于 test；
- 4 个 split 全跑：LGC-val（稳定）、LGC-test（洪水）、CIA-val、CIA-test；
- 主指标 RMSE（论文口径 [0,1]），同时报 MAE/PSNR/SSIM/SAM/ERGAS/CC；
- 每个变体与 E01（fixed-1）做配对比较，统计用 Wilcoxon + bootstrap CI。

---

## A. 校准估计器（数学层面：怎么解那 12 个标量）

### E01 fixed-1（基线）
- 机制：一次去噪输出，不做任何修正。
- 出处：STFDiff（Information Fusion 2024）。
- 假设：无。
- 实验：作为所有变体的参照，报告全部指标。

### E02 identity（不做校准，直接用 coarse 变化）
- 机制：a=1, b=0，T = LP(F_p) + LP(C_t − C_p)。
- 出处：RSAC prior-enhanced initialization（J. Remote Sensing 2026, DOI 10.34133/remotesensing.1035）证明"低频由观测给、高频由生成给"的频率分工在遥感扩散里有效。
- 假设 H2：在辐射一致的数据上，coarse 与 fine 的低频变化近似 1:1，校准反而引入方差。
- 实验：与 E03 对比，判断"校准是否必要"。

### E03 per-band OLS（当前主方法）
- 机制：对每个 band 解 LP(F_n−F_p) ≈ a·LP(C_n−C_p)+b，闭式最小二乘。
- 出处：PRISM（arXiv 2608.15037）把"闭式仿射 → 单次投影"的工程形态走通；Guidance Weights（arXiv 2610.03503）证明标量组的最优解可解析求出。
- 假设 H3：逐样本仿射能吸收目标域的辐射差异。
- 实验：主实验 + 与 E02/E05/E06/E07/E08/E09 比"估计器"优劣。

### E04 bi-avg（双锚平均）
- 机制：T = ½(T_p + T_n)，前后锚各估一次再平均。
- 出处：Exact & Calibrated Diffusion Reconstruction（arXiv 2607.12937）的"投影位置敏感"结论支持在首步后立刻做一次对称投影。
- 假设 H4：双锚平均降方差，在强变化时更稳。
- 实验：与 E03 对比，分别在稳定/洪水 split 上看谁更稳。

### E05 总体最小二乘 TLS（正交回归）
- 机制：把 C 的观测噪声也考虑进去，用 PCA 主轴代替 OLS 斜率。
- 出处：GSC（arXiv 2512.20108）在反演里强调变量含噪时的估计偏差。
- 假设 H5：C_t 本身含配准/重采样噪声，OLS 斜率会被衰减（attenuation bias）。
- 实验：与 E03 比；重点看低变化 patch。

### E06 Deming / 误差变量回归
- 机制：显式给定噪声比 λ_noise = var(e_y)/var(e_x) 的 EIV 回归。
- 出处：同 GSC（arXiv 2512.20108）。
- 假设 H6：噪声比稳定时，Deming 比 TLS 更数值稳健。
- 实验：噪声比取 {0.25,0.5,1.0} 三档（作为内部超参，在 val 上选）。

### E07 Huber 稳健仿射
- 机制：IRLS 加权，抑制 5% 强变化离群像元对斜率的拉扯。
- 出处：DCDP（ICCP 2026）强调解耦数据一致性中的异常观测。
- 假设 H7：洪水/城市边缘的强变化像元是离群点，稳健回归能提升斜率精度。
- 实验：与 E03 比，重点在 flood split。

### E08 Ridge 收缩到 identity
- 机制：在最小二乘里加 (a−1)² 惩罚，把斜率往 1 拉。
- 出处：Guidance Weights（arXiv 2610.03503）的"解析权重 + 正则"框架。
- 假设 H8：小样本（单 patch）拟合方差大，收缩能降方差换偏差。
- 实验：ridge ∈ {5, 50, 500} 在 val 上选。

### E09 变化加权最小二乘 WLS
- 机制：权重 = |LP(C_n−C_p)|，让变化大的像元主导拟合。
- 出处：Patch Forcing（CVPR 2026）"按难度/信息量分配权重"的思想。
- 假设 H9：稳定像元只提供截距信息，变化像元才提供斜率信息。
- 实验：与 E03 比。

### E10 span 归一化斜率
- 机制：把在 anchor 区间（d1→d3）上拟合的斜率按预测区间（d1→d2）长度比例缩放。
- 出处：WaFT（TGRS 2026）把"时间演化分量"单独建模的思路；以及我们自己的发现（anchor span 与 prediction span 不匹配会让斜率偏低）。
- 假设 H10：这是我们 val 上 OLS 反而输给 identity 的原因，修正后 OLS 应全面胜出。
- 实验：**最关键的一个**。若成立，主方法直接升级。

## B. 目标估计（怎么把两侧锚点合成一个 T）

### E11 逆方差加权双锚
- 机制：按每个锚点自身的时间变化幅度加权（变化小的锚更可靠）。
- 出处：Uncertainty-Aware TTA for Cross-Region LST STF（IGARSS 2026, DOI 10.1109/IGARSS60577.2026.11730220）。
- 假设 H11：两锚可靠性不同，等权平均不是最优。
- 实验：与 E04 比。

### E12 直方图匹配（rank-based）
- 机制：把 T 的分布按秩映射到 LP(x1) 的分布，再投影。
- 出处：方向 6（OT/直方图匹配用于跨传感器辐射归一化）。
- 假设 H12：跨传感器时线性仿射不够，单调非线性映射更稳。
- 实验：重点看 CIA。

### E13 OT 仿射（均值-方差传输）
- 机制：per-band 把 T 的均值方差搬到 LP(x1) 上。
- 出处：同方向 6（线性最优传输/颜色迁移）。
- 假设 H13：只对齐一二阶矩就能吃掉大部分域差。
- 实验：与 E12 比，看线性 vs 非线性。

### E14 Conformal / 失配门控
- 机制：λ_i = λ / (1 + |M|/s)，失配越大越少信投影。
- 出处：Conformal Prediction for Remote Sensing（TGRS 2026）的风险控制思想。
- 假设 H14：大失配样本上投影可能过修，门控能降尾部风险。
- 实验：报均值 + 最差 10% patch 的 RMSE（尾部指标）。

## C. 投影算子（在哪个域、用什么滤波、投多强）

### E15 Haar 小波低频投影
- 机制：用 [1,1]/2 可分离低通代替高斯。
- 出处：WaFT（TGRS 2026）、HDW-SR（CVPR 2026）都用小波分离高低频。
- 假设 H15：小波的紧支撑更贴合局部变化边界。
- 实验：与高斯比。

### E16 引导滤波投影
- 机制：以 F_p 为引导做边缘保持低通。
- 出处：HDW-SR（CVPR 2026）"高频引导"。
- 假设 H16：高斯会把洪水边界抹平，引导滤波能保住边界。
- 实验：与 E03 比，看 SAM/SSIM 是否改善。

### E17 双尺度级联
- 机制：先 σ=4 再 σ=2 的级联低通。
- 出处：HDW-SR（CVPR 2026）多尺度。
- 假设 H17：只投最低频更安全，级联能兼顾中频。
- 实验：与单尺度比。

### E18 逐波段 λ
- 机制：λ_k ∝ a_k（斜率大的波段多修）。
- 出处：Guidance Weights（arXiv 2610.03503）的逐组标量解析解。
- 假设 H18：不同波段的 coarse→fine 耦合强度不同。
- 实验：与全局 λ 比。

### E19 逐像元自适应 λ
- 机制：λ(x) 随局部 |ΔC| 增大。
- 出处：Patch Forcing（CVPR 2026）按难度分配算力/强度。
- 假设 H19：变化区需要更强修正，稳定区应少动。
- 实验：与全局 λ 比。

### E20 迭代投影（不动点两次）
- 机制：x ← x − λ(LP(x) − T)，重复两次。
- 出处：PC-DAPS（arXiv 2610.31592）的退火/迭代后验采样。
- 假设 H20：一次投影未收敛，二次能进一步降低频残差。
- 实验：与单次比，同时报 NFE 与耗时（仍是 1 NFE，只是多一次滤波）。

## 实验矩阵与判定

| 维度 | 设置 |
|---|---|
| 变体 | 20（E01–E20） |
| λ | 4 档，val 选，test 用 |
| split | LGC-val / LGC-test / CIA-val / CIA-test |
| 指标 | RMSE, MAE, PSNR, SSIM, SAM, ERGAS, CC |
| 统计 | 与 E01 配对 Wilcoxon；bootstrap 95% CI；胜率 |
| 判定 | 主判据 = 四个 split 的 RMSE 相对变化全部 ≤0 且至少两个 <−2% |

## 预期（写在前面的可证伪预测）
1. E10（span 归一化）若成立，应同时改善 LGC-val 与 LGC-test，成为新主方法。
2. E02（identity）会在 LGC-val 很强、LGC-test 较弱；E03 相反 —— 已在早期实验观察到。
3. E12/E13（OT 类）应在 CIA 上相对更好（跨传感器）。
4. E16（引导滤波）应改善 SSIM/SAM 而非 RMSE。
5. E20（迭代）增益有限（<0.5%），因为一次投影已接近不动点。

## 实际跑完的结果（2026-11-18 02:40）

20 个变体 × 4 个 λ × 4 个 split，全部在真实 LGC/CIA 数据上跑完（脚本 `tools/exp20_final.py`，结果 `results/E20_*.csv`，排行榜 `results/E20_leaderboard.csv`）。
λ 一律在对应数据集的 val 上选、原样用于 test。

| 排名 | 变体 | LGC-val | LGC-test | CIA-val | CIA-test | 最差 |
|---|---|---|---|---|---|---|
| 1 | **E14 失配门控** | **−3.47** | −6.98 | **−4.46** | **−3.44** | **−3.44** |
| 2 | E08 Ridge 收缩 | −2.55 | −6.74 | −1.25 | −0.99 | −0.99 |
| 3 | E07 Huber | −2.17 | −6.74 | −0.97 | −1.35 | −0.97 |
| 4 | E09 变化加权 | −2.03 | −6.63 | −0.96 | −1.04 | −0.96 |
| 5 | E15 Haar | −1.78 | **−7.48** | −0.91 | −1.05 | −0.91 |
| 6 | E03 OLS（旧主方法） | −2.05 | −6.73 | −1.08 | −0.90 | −0.90 |
| … | … | | | | | |
| 18 | E02 identity | **−23.15** | **+7.80** | +0.60 | −2.89 | +7.80 |
| 20 | E05 TLS | +9.90 | +18.16 | +16.09 | +9.12 | +18.16 |

**结论**：
1. E14（从 Conformal / 不确定性 TTA 借来的失配门控）是**最差 split 最好、均值最好**的变体，且是唯一四个 split 都优于 −3% 的。
2. 13 个变体在四个 split 全为负，说明"投影"本身是有效的；差别在于**校准是否可信**。
3. identity 在 LGC-val 上 −23%（全场最佳）却在 LGC-test +7.8%——最强的"regime 反转"证据，说明任何固定强度都不可靠。
4. TLS 全场最差（+9.9~+18.2%），因为正交回归会把本已衰减的斜率过度修正。
5. E10（span 归一化）在本实现里退化为 E04，已如实标注为未验证假设。

**方法学结论**：不是"找到更好的估计器"，而是"承认估计有方差并按可信度衰减"。这直接支撑论文新主线。
