# 首要实验与后续研究计划

版本：2026-11-19 v1。当前阶段：E00 审计部分完成，尚未完成外部 SOTA 正式对比。

## 1. 研究主线

目标是做出有充分机制依据、在相同公共数据基准上优于有竞争力方法的时空融合算法。完整逻辑：

1. 用可靠的外部强方法和基础模型，定位真实失败模式。
2. 提出一个可解释、可实现、与已有方法有清楚区别的机制。
3. 只改变该机制，控制数据、训练与采样，证明收益确实来自它。
4. 在相同目标日期、区域、波段、观测条件、掩膜和评测代码下比较外部方法。
5. 用多种指标、跨日期/跨数据集、多个随机种子及可视化，确认收益与代价。

“比项目自己过去的模型好”不足以支持超越 SOTA；提高训练预算的收益也不归到结构创新。网络模块、训练机制或推理算法都可以有方法贡献，但创新程度须由问题、推导、与既有方法的区别和证据共同判断。达到分数门槛也不自动保证录用。

### E01：外部对照的执行顺序

| 层次 | 方法 | 目的 | 执行条件 |
|---|---|---|---|
| 简单下限 | 前锚复制、时间距离加权双锚插值、直接 coarse change 迁移 | 排查数据与深度模型是否真的优于简单做法 | 无需训练；明确都是控制组 |
| 直接基础模型 | STFDiff：官方双锚采样、1/2 步、旧 RLF 后处理 | 获得正确基础线，拆开训练、步数、η 与后处理贡献 | 旧训权重只作诊断；正式控制要同配方训练 |
| 当代强对照，最高优先 | SA-STF（CVPR 2026） | 检验相对于强扩散方法的实际差距 | 代码已到位；权重、日期覆盖、适配器待核 |
| 可运行深度对照 | SwinSTFM | 检验是否超过有代表性的 Transformer 方法 | 本地统一仓库已有实现；权重或重训协议待核 |
| 补充当代强对照 | STFMamba（ISPRS 2025） | 覆盖状态空间模型 | 不假设权重已公开；先检查依赖，不以降配实现冒充原模型 |
| 传统代表 | ESTARFM 优先，Fit-FC/FSDAF 后续补足 | 保留传统强基线，检验稳定场景 | 先查作者实现与许可证；自写近似版不能冒充官方复现 |
| 文献跟踪 | DPDiff（2026） | 覆盖近期相关机制 | 当前作者代码未发布，记为不可复跑，不虚填表 |

先让 **SA-STF + 正确 STFDiff + 一个可运行外部代表** 形成最小有用对照，再扩全；不能用“跑了几种传统方法”代替当代强方法比较。某项依赖暂时不可用时，继续其它项，不让一个 CUDA 扩展拖住整个研究。

### 两类比较，分别回答两个问题

- **公开方法复现表**：遵循各作者推荐训练配方，使用同一套正式评测样本。记录官方预训练或本地重训、所有额外训练数据、预算、NFE。训练日期有交叉或无法核实的预训练输出，只作为探索数据，不进入干净排名。
- **机制因果表**：基础模型与本文模型，同训练/验证数据、初始化种子、优化器、更新次数、增广、选模、推理设置；仅开关目标机制。另报收敛曲线与计算预算，避免把更大训练量当创新贡献。

**E01 产出：** `work/results/benchmark_v1/` 的逐 patch/逐日期结果、整图结果（数据完整时）、协议与权重哈希、各指标主表、失败案例记录。旧 test 已用于多轮搜索，所以先明确标为开发复核；确认性评估按协议另行执行。此时没有超过强方法，就如实记录差距并作为下一阶段靶点。

## 3. E02：只集中一个机制，建立真正的因果闭环

### 先问清楚的机制问题

旧结果提示“照搬粗影像低频变化”在部分场景有效、部分场景会负迁移。待检验的研究问题是：**能否在去噪网络内识别粗观测变化的局部可信程度，并据此更新预测，而不是固定系数地把所有粗变化都当真？**

这是待验证假设，不把 a=0.54 当物理定律，也不把一次低 R² 当信息上限。先基于 E01 的统一误差图检查：稳定区、变化区、水体边界、传感器差异处是否存在一致可解释的缺陷；若现象不成立，就不据此造模块。

### 首选候选：可靠度约束的观测残差更新

作为研究草案，先不命名“新 SOTA”：

1. 构造两锚点提供的低频时间变化目标：`T_i = LP(F_i) + A_phi(C_t, C_i, F_i)`。`A_phi` 是有界、轻量的传感器变化映射，不硬编码 0.54。
2. 从合法观测条件中预测空间/波段可靠度，并按实际时间间隔融合两个目标。可靠度在训练集上用可观察预测误差校准；推理时只读 F0/F3/C0/C1/C3。
3. 在去噪器的中间特征或 x0 预测分支引入 `LP(x0_hat)-T` 的受控更新，和恢复细节的分支联合训练；关闭更新应能退回基线。禁止只把旧 RLF 外置包装成网络创新。
4. 所有目标日 fine 信息仅进入训练监督，不进入推理可靠度或动态超参。可靠度必须有可检验的误差排序能力；若退化为常数，应降级为固定门控控制，而非继续宣称“自适应”。

这与 SA-STF 的 TFA/SAF、DPDiff 的双先验、传统回归补偿可能存在重合。**实现前必须逐公式/结构做差异表；若只是等价改写，停止该候选。** 新颖性的判断是本阶段工作，不是本计划已经证明的结论。

### 最小训练矩阵

| ID | 内容 | 回答的问题 |
|---|---|---|
| M0 | 正确协议下的 STFDiff 基础模型 | 干净参照 |
| M1 | M0 + 原 RLF，冻结后处理参数 | 旧增益能否重现 |
| M2 | 只加入可学习变化映射，可靠度固定 | 映射是否有贡献 |
| M3 | 只加入可靠度控制，映射用 identity | 是否确实需要自适应可信度 |
| M4 | 完整候选 | 两者是否互补 |
| M5 | 与 M4 近似参数/计算量的普通残差块 | 是否只是多了容量 |

先用 seed=42 运行 M0/M4 可行性实验；有明确验证收益再补 M2/M3/M5 与 seed=123、2026。M1 不需重新训练。阶段选择只看冻结的验证集；不根据旧 flood/test 分数决定结构。旧 `delta/gate/reinject` 和 `delsup` 保留历史位置；修复 delsup 是控制实验，不预设其有效。

### 停止和晋级规则（工程决策，不是录用标准）

- M4 与配对 M0 在完整验证上没有约 1% 的 RMSE 改善，或收益完全由单一日期/单个噪声种子解释：不进入大规模矩阵；先做一次定位修正，仍无收益就换假设。
- 进入多种子后，目标是约 2% 以上相对 RMSE 改善，至少多数训练种子同向，并展示逐日期结果。该数值是预设投入门槛，不用它筛掉不利测试结果。
- SSIM/CC 下降或 SAM/ERGAS 变差时同时报告；若其它关键指标约 1% 以上相对退化，先定位权衡，不能称“全面优于”。最终阈值在正式运行前随协议冻结。
- 自适应门控若和误差/不确定性无关联、打乱可靠度图不影响结果，相关机制解释被否证；即使总分有提升，也按真实作用重新解释。
- 正式锁定测试若未超过最强可比外部方法：不得写精度 SOTA；若只能取得明确效率优势，则需用户研究目标允许且完整验证后才能改论文定位。

## 5. 资源与执行纪律

- 当前 RTX 4050 6 GB，D 盘可用约 15 GiB。串行安排 GPU 任务；外部方法先测单 patch，不先装多套大环境或下载全部权重。
- 旧训练约 150–213 秒/epoch，40 epoch 约 1.7–2.4 小时，仅可估计当前 STFDiff。新的数据量、验证和 SA-STF/STFMamba 会改变预算，先实测再排。
- 参考节奏：E00 余项约半天到一天；最小 E01 约 1–3 天（取决于权重和数据获取）；M0/M4 初筛约 4–8 GPU 小时再校正；完整多种子与外部重训通常还需数天。不是完成时间承诺。
- 每次运行独立 `run_id`，存配置、数据 SHA、源码 commit/差异、权重 SHA、种子、日志、逐样本输出和选择规则。`best`/`last` 不跨实验覆盖。
- 大缓存按当前实验预估容量；低于 8 GiB 暂停新增大下载并盘点，不自动删现有缓存。先复用与打包小型可审计元数据，避免重复复制全部权重。
- 新结果放 `benchmark_v1/`，旧 `FINAL_*` 不覆盖；只在所有预定实验完成后发布带版本的冻结结果。
