## 2. 定位原版在变化区的失效

- 在开发场景先检查 LGC 洪水边缘、新增淹没区和稳定区。CIA 按实际影像标记有证据的地表变化。用目标日精细参考相对双锚按日期插值的残差幅度标记强变化，提前在开发集固定阈值和有效像素规则。参考真值和变化掩膜只用于评估，图例按固定规则选择。
- 用变化区 RMSE、稳定区 RMSE 和逐场景误差图量化漏恢复、旧边界残留和伪变化。对有可靠水域标注的场景补充新增水域召回和稳定区域的误报。
- 固定基线权重与噪声，分别用锚间粗图插值代替目标日粗图，以及在块内置乱粗图时间残差。比较原版输出的变化、误差和可访问的融合特征，检验模型依赖的日期信息和空间对应。输入扰动用来定位问题，最终机制归因由重训对照完成。
- 在多个开发日期或事件上检查同类误差。根据可重复的现象决定改哪个计算环节。例如，若模型反复把真实变化扩散到同一粗像元内的稳定区，就测试新的变化分配算子。粗观测约束细分辨率变化经传感器降采样后的量，两端精细观测提供粗像元内变化的候选位置。用同容量残差分支和仅加观测一致性损失的变体区分这项改动的作用。

## 3. 对照移植 I10 和设计新机制

| 实验 | 配对方式与判定 |
| --- | --- |
| 原版与移植版 | 在同一个强基线内移植 I10 的双锚权重和目标日粗偏差支路。原版和改造版用相同输入、初始化来源、优化步数与采样设置，检查变化区相对原版的收益和开销。 |
| 时间信息干预 | 固定权重配对比较原样、粗偏差置零、块内置乱和移除整条注入，测输出及投影改变量。再重训无粗偏差变体，验证模型在同等训练机会下是否依赖该信息。 |
| 容量与表示控制 | 加入相近参数量的原始反射率残差分支，并比较可学习的常量条件。同步记录通道占用、权重熵和修正幅值，判断收益是否来自空间对齐的目标日信息。 |
| 针对性算法改造 | 根据第 2 步的诊断选择一个环节，写清原版计算、改动的算子和可被反证的预测。用同预算重训及单项消融评估新算法，并与直接移植版对照。 |

移植版表现退化时复核归一化、注入强度和训练曲线，再检查诊断结果。若时间偏差干预的响应接近噪声且容量控制拿到同等成绩，暂停原 I10 的时间修正方案，依据已验证的失效继续设计。八通道图用于展示潜在权重及其变化，材料含义需要独立标注或物理约束验证。

定案前逐式对照 SA-STF 的时序对齐与语义自适应融合、DPDiff 的时空双先验、STF-FlowDiff 的显式时序引导和 SPP-STF 的退化一致性约束。交付原版与新算法的计算差异、适用条件和对应消融。 [SA-STF 论文](https://openaccess.thecvf.com/content/CVPR2026/html/Zhang_Semantic-Adaptive_Diffusion_for_Dynamic_Spatiotemporal_Fusion_CVPR_2026_paper.html) · [DPDiff 作者仓库](https://github.com/paul623/DPDiff) · [STF-FlowDiff 论文](https://doi.org/10.1109/TGRS.2026.3687438) · [SPP-STF 论文](https://doi.org/10.1080/15481603.2026.2741478)

## 4. 独立确认与论文主表

- 在独立测试前冻结主模型、对照、数据日期、变化分组、选模规则及稳定区和开销的容许范围。按日期审计训练、选模、历史调参和参考影像的暴露，再使用未参与开发的 LGC 日期及 CIA 评价。CIA 域内训练与跨域评价明确标注。
- 主表至少包含选定强基线原版、同骨干的最终改造版及其关键消融，并保留可公平复现的其他强方法。原版和改造版配对跑三个训练种子，报告逐日期、逐种子差值、变化区与稳定区表现、NFE、端到端推理延迟和峰值显存。
- 以场景和空间块为统计单位。块内同噪声配对，噪声重复在各块内汇总。以独立日期验证收益的可复现性，保留退化案例。
- 论文需要三项对应证据。原版失效可复现。新算法在容量和时间信息控制后仍有独立贡献。独立日期上的变化恢复与精度有所改善，成本在预定范围内。

## 已有 I10 协作小实验

现有脚本使用 seed 42 的固定权重。同一块的所有模式使用相同噪声和一次主干调用。默认从按坐标排序的 120 个验证块中等间隔选 24 块，每块 1 次。完整诊断扩到全部 120 块及每块 3 个噪声，seed 123 需要按同口径接入其权重。

| 模式 | 推理干预 | 用途 |
| --- | --- | --- |
| base | seed 42 第 32 轮基线原样推理 | 保留同协议的分数参考 |
| i10_full | seed 42 第 32 轮 I10 原样推理 | 校验重建与条件的参考值 |
| i10_no_coarse_delta | 推理时将粗成分偏差系数置 0 | 检查已训练模型对目标日粗偏差的依赖 |
| i10_shuffle_coarse_delta | 在每块内将 32×32 粗偏差子块按固定种子置乱 | 检查空间对应。子块内部值与通道联合保留 |
| i10_no_injection | 移除成分投影增量，保留原始条件 | 检查已有 I10 权重对整个成分条件的依赖 |

使用 [i10_probe.py](../scripts/i10_probe.py)，按 [数据集与协作手册](DATASET_MANUAL.md) 恢复环境、切片与检查点。结果文件包含每块每次噪声的 RMSE、SAM、SSIM、ERGAS 和 CC，同块配对差值可从明细复算。诊断另记录熵、最大权重、各通道占用率，以及移除或置乱偏差后的投影变化。若投影改变量和误差变化都接近零，优先检查成分集中或近常数注入。

保留全部模式和重复的逐块结果。固定权重的敏感性与从零训练的配对控制共同用于判定机制贡献。
