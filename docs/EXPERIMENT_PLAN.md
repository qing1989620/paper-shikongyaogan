### 初筛冻结与晋级

- 配置：work/configs/screening_2026/queue_v1.json；不再根据中途分数改训练/验证样本。
- 所有方向从相同旧训 base 权重出发，完整 train=1200、val=120，6 epoch、seed=42、三组稳定推理噪声。原型没有访问 test 标签做选择。
- 初筛约 1% RMSE 改善仅决定优先顺序，并检查其它指标和噪声稳定性；基础微调若退化，还必须超过原始第 0 轮控制，不能只比变弱的 base。初筛不淘汰其余方向。
- 按用户“每个创新做严谨实验”的要求，后续控制进程采用 `followup_v2.json`，对 base+全部 14 方向从零训练 40 epoch × 三 seed，共 45 run。初筛较好的方向先跑；v1 的“两候选充分训练”方案保留作历史，不再作为当前执行范围。
- 全部 45 run 完成后，仅依据开发 val 选择最多两个外部评测候选：平均 RMSE 至少改善 1%，三个训练种子各自配对改善，且每个 seed 的 SSIM/CC/SAM/ERGAS 均无超过 1% 的相对损害。没有通过时，外部运行标为诊断，不能称胜出。此时仍需逐日期证据、机制反证、容量/预算控制与独立确认。
- 已安排的 SA-STF 共同 flood patch 重跑使用作者预训练权重，与本项目 10 组训练配方不同，只作明确标注的补充比较。论文主表还需共同训练协议，或按作者公开配方训练本方法；不能只统一测试 patch 就把不同训练数据带来的差距写成算法贡献。
- 六轮结果不构成失败定论，若明显未收敛记录为预算不足。特别是改变生成过程的模型，不能用短微调否定其充分训练潜力。
- 路由/可靠度坍缩、误差校准不成立、置乱不影响结果时，相关解释应被否证，不能只挑总分写故事。
- 14 次探索的多重比较、旧 test 暴露历史、LGC 单个 val 日期的局限均记录；独立确认性数据和正式 protocol_v1 仍需锁定。
