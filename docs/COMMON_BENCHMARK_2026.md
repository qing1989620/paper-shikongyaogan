# 与 SA-STF 的共同基准：已核对的日期与剩余边界

2026-11-19，来源为 `references/papers/SA-STF_CVPR2026_supplemental.pdf` 第 3 页 Table 3。已提取文本并渲染整页目视核对，结构化记录见 `audit/sa_stf_protocol_from_supplement.json`。

## 已确定

- SA-STF 的 LGC 训练组包括 2005-03-02，因此我们的旧 LGC val 不能作为它的干净验证集。
- SA-STF 的 LGC 测试三元组为 2004-12-28 → 2005-01-13 → 2005-01-29，与我们现有 flood test 完全对应。该目标 fine 日期不在其公开训练三元组的 fine 日期中。
- CIA 补充材料使用 Landsat 文件日期，现有元数据用配对目录日期。逐文件核对发现 CIA fine 文件日期比配对目录标签早一天。其公开测试 2002-04-10 → 2002-04-17 → 2002-04-26 对应我们的 `test2`：2002-04-11 → 2002-04-18 → 2002-04-27。不能把其它 custom test 组不加说明地当成其原测试协议。
- 作者提供的 LGC 权重已严格加载 297 个 state-dict 项、83,839,558 个参数值；小尺寸 50 步采样通过。推理适配器只跳过训练用 VGG 分配，采样方法 AST 保持一致。

“不交叉”以作者公开训练协议和其标为 LGC 的发布权重为依据；二进制本身没有日期元数据，不声称独立证明了作者的完整训练历史。

## 不能混淆的比较

作者补充材料给出 LGC test=361 patch，而我们的现有 flood test=120 个非重叠 patch。训练组和训练预算也不同。因此：

1. 不把论文自报绝对分数直接放进我们的 120-patch 结果主表。
2. 可以让作者模型和项目模型对**同一组 120 patch、相同五观测、同反射率指标**重新推理，明确这是共同 patch 协议的新实测，训练配方差异单列。
3. 各方法保留本身采样规则，SA-STF=50 步；STFDiff=1 步及官方双锚 η=0 的 10 步分列。新增模块计算成本仍需单独报告。
4. 目前只固定共同裁剪为左上 2560×3072 的非重叠 256 tile，所有方法使用相同有限像素；不据 patch 数推断作者的精确裁剪，也不冒充复现了论文的整图 361-patch 协议。
5. 这一场景已经用于历史开发，不能称为新的盲测确认。最终论文仍需 CIA、充分消融、独立性和训练资源控制。
6. **相同测试 patch 仍不足以完成训练公平性控制。** 这轮作者预训练权重与项目 10 训练组的比较属于补充性新实测；不能把其中差距全部归因于算法。正式主表还需作者公开训练日期/共同训练样本与输入预算的匹配重训，或按作者协议训练本方法并清楚列出选模与训练资源。当前共同 patch 表不解除这道关卡。
